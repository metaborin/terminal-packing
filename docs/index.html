端末番号の一覧

番号一覧はまだ登録されていません。

CSV・テキストを読み込むか、Excelの端末番号の列をコピーして貼り付けてください。

端末番号は8桁。CSVの列名は「端末番号」「管理番号」に対応。梱包済みの番号が消える一覧への変更はできません。

02 / 記録の控え

バックアップを保存

番号一覧と梱包記録をまとめて保存できます。箱ごと・作業終了時に「ファイルに保存」を選んでください。

このiPhoneのブラウザ内に保存されます。閲覧データを消すと記録も消えるため、控えを残してください。

ホーム画面に追加

  1. このページをiPhoneのSafariで開きます。
  2. 共有メニューから「ホーム画面に追加」を選びます。
  3. 「Webアプリとして開く」が表示されたらオンにし、「追加」を押します。
  4. ホーム画面の「回収ノート」アイコンから開きます。

「ホーム画面に追加」が見つからない場合は、共有メニューを下へスクロールしてください。PCなどではブラウザの「アプリをインストール」メニューも利用できます。

既に記録がある場合は、追加前にバックアップを保存してください。新しいアイコンで記録が表示されない場合は、そのバックアップから復元できます。
